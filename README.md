# Super 3T

Ultimate Tic Tac Toe: a 3×3 board where every cell is another tic tac toe. The cell you play
decides which board your opponent plays next.

## Requirements

- Node 24.22.3 (`.nvmrc`) and npm 11
- [Task](https://taskfile.dev) v3

## Usage

```sh
task setup   # install from the lockfile
task dev     # http://localhost:4200
task check   # format, lint, tests and build (same as CI)
```

Run `task --list` to see every task.
